# Archive

## srtgn-timetable-2023/

SRTGN (Société Régionale de Transport du Gouvernorat de Nabeul) winter timetable,
"valid from 1 September 2023", 4 pages covering all Nabeul-region lines
(including Zaghouan–Tunis 840/802, Zaghouan–Nabeul 841/141/940, Zaghouan–Sousse 842).

- Previously shown as a photo gallery on `/transport` (as `public/images/transport/BUS (1–4).webp`).
- Archived on 2026-11-19: SRTGN's live timetable (http://www.srtgn.com.tn/site/horaires) differs —
  Zaghouan→Tunis 13:00 and Tunis→Zaghouan 14:30 / 16:00 no longer run.
- The current times are in `src/data/transport.ts`.
