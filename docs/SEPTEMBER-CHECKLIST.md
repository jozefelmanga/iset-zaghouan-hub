# September checklist

Every September (before new students arrive), re-check the facts below against the source, edit the file, then update the dates. Takes about an hour.

When you're done:

1. Update `ACADEMIC_YEAR` in `src/constants/seo.ts` (page titles use it).
2. Update the months in `src/data/last-updated.ts` for every page you re-checked.
3. Run the checks in `CLAUDE.md` (`npm run test` catches FAQ answers drifting from the data).

## Facts to re-check

| Fact | File | Where to check |
|---|---|---|
| Bourse papers list | `src/data/scholarships.ts` → `scholarshipDocuments` | OOUN (ديوان الخدمات الجامعية للشمال) notice, or faccna.tn |
| Bourse deadline (15 days after enrollment) | `src/data/scholarships.ts` → `scholarshipDeadlineDays` | OOUN notice |
| Bourse amount (1320 DT, 4 instalments), insertion grant (500 DT), income thresholds | `src/data/scholarships.ts` | OOUN or tawjih.tn |
| Enrollment papers | `src/data/enrollment.ts` → `enrollmentDocs` | ISET Zaghouan's official Facebook page / scolarité |
| E-dinar Jeune card price (15 DT) | `src/data/enrollment.ts` | La Poste Tunisienne |
| Foyer papers, deposit (20 DT), curfew | `src/data/housing.ts`, `/inscription/foyer` page | Foyer administration, OOUN |
| Bus timetables | `src/data/transport.ts` → `busTimetables` (+ update `busTimetableSource.checked`) | http://www.srtgn.com.tn/site/horaires |
| Louage and bus fares, abonnement (45 DT / semester) | `src/data/transport.ts` → `transportRoutes`, `transportAbonnement` | Regional transport office in Zaghouan, or a current student |
| Louagiste contact | `src/data/transport.ts` (route `louage`) | Call the number |
| Resto hours, ticket prices | `src/data/restaurant.ts` | The resto, or a current student |
| Stage deadlines and rules | `src/data/internships.ts` | Stages office |
| Institute phones, email, address | `src/data/official.ts` | isetzg.rnu.tn |
| Company list for internships | `src/data/stage-companies.json` (generated by `scripts/generate-stage-companies.mjs`) | New xlsx from the stages office |
| Zan9a banner numbers (rating, customers) | `src/components/sections/Zan9aStickersSection.tsx` → `PERKS` | zan9a.tn |

The FAQ (`src/data/faq.ts`) is built from these files, so you don't edit FAQ answers for papers, bus times, fares or resto hours: fix the source file and the FAQ follows.
